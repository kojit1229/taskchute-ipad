# 作業一覧(v443 束A)

先頭の「決めること」は、期日管理対象Projectの未完了タスクを集計する。「超過」「今日」「7日以内」「期日なし」を押すと一覧を絞り込み、もう一度押すと解除する。「期日なし」の件数はシリーズをまとめた数。

「期日を決めてほしいもの」には、親にも期日のないタスクを作成が古い順に最大5件出す。題名・Project・提案日・理由・曜日を表示する。この段階では「M/D に」「📅」「期日なし…」の操作は無効。表示は「今日 0/5 件」で、採用や保存は後続の束Bで扱う。

Projectチップと題名検索で対象を探す。検索は題名だけを対象とし、複数語はすべてを含む題名に一致する。子だけが一致した場合も親を薄字で案内する。Projectの見出しで一覧を開閉できる。

「物語 1巻」「物語 2巻」や「ジム①(補足)」「ジム②」は、同じProject・同じ親の未完了シリーズとして先頭だけを表示する。「+N件」で残りを展開する。検索中は全件を表示する。「過去問 第3回」「2026年」「無職転生 3期」はシリーズとしてまとめない。

行には着手中・カテゴリ・超過日数・作業期限・期日・見積を表示する。通常の作業期限は期日の2日前で、既存の前倒しOFF設定を尊重する。期日と見積は表示のみで、題名から既存の編集画面を開ける。完了・中断は「その他」の既存設定に従う。

狭い画面では縦に並び、900px以上では「決めること」と検索が左400px、一覧が右に並ぶ。1280px以上ではProjectの箱が2列になる。

## 現差分の保留事項

12週目標の週末を提案日に使うための実データ項目が発注に未指定のため、その分岐は未実装。現時点では作成日+14日、候補が今日+2日未満なら今日+5日を表示する。既存ヘッダーの旧表示ツールの整理も変更範囲の確認待ち。
