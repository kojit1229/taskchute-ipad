# 作業一覧・決めること(v443 束A、発注02改訂版)

作業一覧はProject→タスク→子の全体計画を表示する。「一覧」の下に未完了全体の「超過」「7日以内(今日を含む)」「期日なし」、題名検索、Projectチップが並ぶ。期日なしはシリーズをまとめた件数。チップは再度押すと解除する。

「物語 1巻」「物語 2巻」や「ジム①(補足)」「ジム②」は、同じProject・同じ親の未完了シリーズとして最小番号だけを表示する。「+N件」で残りを展開する。検索中は全件を表示する。「過去問 第3回」「2026年」「無職転生 3期」はまとめない。

検索は題名だけを対象とし、複数語はすべてを含む題名に一致する。子にも同じ絞り込み条件を適用し、子だけが一致すれば親を薄字の「(条件外の親)」として案内する。親の▾/▸で子を開閉できる。

Project見出しには名前・カテゴリ・畳んだ件数/元の件数・進捗・12週計画の週・期限超過を表示する。行には着手中・進捗・超過日数・作業期限・期日・見積を表示する。作業期限は通常期日の2日前で、既存の前倒しOFF設定を尊重する。期日と見積は表示のみで、題名から既存の編集画面を開く。完了・中断は既存の表示設定に従う。

狭い画面では縦に並び、900px以上ではチップ・検索・Projectチップが左400pxのsticky欄、一覧が右に並ぶ。Projectの箱はPCでも1列、行は題名・情報・期日/見積の3列。

「期日が決まっていないもの N 件 → 決めること」で別タブへ移る。このタブはサイドバーと「その他」からも開ける。下部ナビは6枠のまま。

「決めること」は期日管理対象Projectの未完了タスクだけを集計する。「超過」「今日」「7日以内(翌日から7日後)」「期日なし」を押すとタブ内に対象を共通行で表示する。「期日なし」の件数はシリーズをまとめた数。

「期日を決めてほしいもの」には、親にも期日のない対象を作成が古い順で最大5件出す。提案は12週計画中の今週金曜(今日以降)、作成日+14日の順。作成日基準の候補が今日+2日より前なら今日+5日。題名・Project・提案日・理由・曜日を表示する。

この段階の表示は「今日 0/5 件」。「M/D に」「📅」「期日なし…」は無効で、採用・編集・リマインドの保存は束B、日程表示は束Dで扱う。
