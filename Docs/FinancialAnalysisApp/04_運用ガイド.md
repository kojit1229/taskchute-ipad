# 04. 運用ガイド(想定)

「毎四半期、決算公開日にさっと入力 → すぐ分析」のリズムを守るための手順書。
1銘柄あたりの所要時間目安: **入力2〜3分+確認1分**。

---

## 1. 四半期サイクル全体像

```
決算シーズン前(月初)          決算公開日ごと                シーズン終了後
┌──────────────┐   ┌──────────────────────┐   ┌──────────────┐
│ 次回決算予定日を  │→ │ 入力(2〜3分/銘柄)      │→ │ バックアップ取得 │
│ 銘柄に設定       │   │ → ダッシュボード確認    │   │ 横断レビュー     │
└──────────────┘   └──────────────────────┘   └──────────────┘
```

## 2. 決算公開日のチェックリスト(1銘柄ごと)

1. [ ] 決算短信PDFを開く(適時開示 or 企業IRページ)
2. [ ] アプリのホームで該当銘柄の「⏳入力待ち」をタップ(入力フォームが当期プリセットで開く)
3. [ ] **短信サマリー(1ページ目)から転記** — フォームの並びは短信の記載順:
   - 売上高 / 営業利益 / 経常利益 / 純利益(いずれも累計値をそのまま)
   - 総資産 / 自己資本 / (有利子負債)
   - 営業CF(Q1/Q3非開示の会社はスキップ)
   - 期末発行済株式数(自己株控除後)
   - 通期予想(売上・営業利益・純利益・年間配当)、予想修正の有無
4. [ ] 各欄の下に出る**前年同期値と桁が揃っているか**目視(桁ズレ検出)
5. [ ] 保存 → ダッシュボードで確認:
   - [ ] KPIカードのYoYが決算資料の説明と整合しているか
   - [ ] 赤信号が出ていれば理由をタップして中身を確認、`note` 欄に所感をメモ
   - [ ] (任意)発表翌日の株価を入力してPER/PBRを記録
6. [ ] 銘柄の「次回決算予定日」を来四半期の予定日に更新

## 3. 決算シーズン終了後(四半期に1回)

1. [ ] 設定 → **JSONエクスポート**を実行し、iCloud Drive等の既存バックアップ先へ保存
   (localStorageはブラウザデータ消去で消えるため、これが唯一の正式バックアップ)
2. [ ] ホームの一覧をヒートマップ表示で横断レビュー(セクタ内の相対感を確認)
3. [ ] 全銘柄の「⏳入力待ち」が消えていることを確認(=入力漏れゼロ)
4. [ ] 未保有化した銘柄はタグを「監視」へ変更 or アーカイブ(削除はしない。時系列は資産)

## 4. 誤入力に気付いたとき

1. 銘柄詳細の期次テーブルで該当期の行をタップ → 入力フォームが編集モードで開く
2. 修正して保存(履歴は残らない。全指標は再計算されるので他に作業は不要)
3. 期そのものを間違えて登録した場合は、フォーム内の削除ボタン → 正しい期で再入力

## 5. メンテナンス手順

### 日常(何もしない)

- サーバー・DB・課金なし。放置してもコストも劣化もない

### アプリ更新時

1. 変更を `main` に push → GitHub Pages が自動反映
2. データ構造を変える場合は `version` をインクリメントし、`app.js` のマイグレーション関数に
   旧→新変換を追加(TaskChute Journal と同じ流儀)
3. iPad側は PWA を開き直し、service worker の更新を確認

### 端末移行・復旧

1. 旧端末(またはバックアップ先)の最新エクスポートJSONを用意
2. 新端末でアプリを開き、設定 → インポート → 全置換
3. ホームの銘柄数・最新期を目視確認

### 年1回の棚卸し(本決算シーズン後を推奨)

- [ ] 赤信号しきい値(03_仕様書 §5)が自分の判断感覚とズレていないか見直し
- [ ] 「欲しかったのに無かった指標」があれば `metrics.js` にエントリ追加
- [ ] バックアップJSONの世代整理(直近4世代残せば十分)

## 6. トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 指標が「—」表示 | 算出に必要な項目が未入力(例: 前Q未入力で単Q算出不能)。該当期を入力すれば自動で埋まる |
| 単QのYoYが出ない | 前年同期(4期前)のデータが必要。過去期を遡って入力する |
| CF系指標が出ない | Q1/Q3にCFを開示しない会社は正常動作(半期のみ表示される) |
| データが消えた | ブラウザデータ消去が原因。最新エクスポートJSONをインポートで復元 |
| 進捗率が異常値 | 通期予想の入力桁を確認(百万円単位) |
