# 決算書分析Webアプリ「Kessan Board」仕様設計ドキュメント

投資家K本人の個人利用を想定した、四半期決算分析Webアプリの要件定義・仕様書一式。

## 設計コンセプト

> 一度作ったら、毎四半期の決算公開時に「さっと入力 → 分析結果がすぐ見える」
> リズムで使い続けられること。

- **1銘柄の入力は2〜3分で完了**する入力フォーム設計
- 開いた瞬間に「どの銘柄が要注意か」「どの銘柄が未入力か」が分かるホーム画面
- TaskChute Journal PWA と同じ技術スタック(依存最小・GitHub Pages・localStorage)で、
  メンテナンスコストを既存ツールと共通化
